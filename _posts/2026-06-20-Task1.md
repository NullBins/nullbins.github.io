# IT네트워크시스템 제1과제

IMG : Debian GNU/Linux 13.2 (trixie)

이 문서는 과제지와 채점기준의 23개 채점 항목을 모두 연결한 순차 실행형 구축 문서다.  

문서 내 명령은 Debian 13.2(trixie) 기준.  
단, VMware NIC 이름, FILE 추가 디스크 장치명, DLBD 1 장치/ISO 경로는 실제 VM에서 확인한 값으로 바꿔야 한다.


## 먼저 알아야 할 유일한 예외

VMware가 부여하는 NIC 이름과 FILE 서버의 추가 디스크 이름은 설치 환경마다 달라진다. 따라서 아래 두 종류의 값만 실제 VM에서 확인해 치환해야 한다.

```vim
ip -br link
lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS
```

이 문서의 예시는 다음 이름을 사용한다.

| 장비 | 인터페이스 예시 |
|---|---|
| R1 | ens33=FW, ens34=R2, ens35=R3 |
| R2 | ens33=R1, ens34=br.itnsa.com LAN |
| R3 | ens33=R1, ens34=worldskills.org LAN |
| FW | ens33=R1, ens34=172.16.10.0/24, ens35=172.16.20.0/24 |
| 나머지 서버/클라이언트 | ens33=해당 LAN |
| FILE | /dev/sdb=100GB, /dev/sdc=50GB |

NIC나 디스크 이름이 다르면 해당 이름만 바꾼다. IP 주소, 포트, 경로, 도메인, 사용자 이름은 바꾸지 않는다.

# 3. EXTERNAL Root CA와 서비스 인증서

채점은 `/etc/ssl/RootCA/cacert.pem`, `CA:TRUE`, 그리고 `newcerts` 아래의 RootCA 및 6개 서비스 인증서를 검사한다.

EXTERNAL에서 수행한다.

```vim
apt install -y openssl
mkdir -p /etc/ssl/RootCA/{private,certs,newcerts,csr}
chmod 700 /etc/ssl/RootCA/private

openssl genrsa -out /etc/ssl/RootCA/private/cakey.pem 4096
openssl req -x509 -new -sha256 -days 3650 \
 -key /etc/ssl/RootCA/private/cakey.pem \
 -out /etc/ssl/RootCA/cacert.pem \
 -subj "/CN=RootCA" \
 -addext "basicConstraints=critical,CA:TRUE" \
 -addext "keyUsage=critical,keyCertSign,cRLSign"

cp /etc/ssl/RootCA/cacert.pem /etc/ssl/RootCA/newcerts/00-RootCA.pem
```

인증서 발급 함수:

```vim
vim /usr/local/sbin/issue-cert
```



```vim
#!/bin/bash
set -e
NAME="$1"
CN="$2"
SAN="$3"
TYPE="$4"
BASE=/etc/ssl/RootCA

openssl genrsa -out "$BASE/private/$NAME.key" 2048
openssl req -new -key "$BASE/private/$NAME.key" \
 -out "$BASE/csr/$NAME.csr" -subj "/CN=$CN"

{
 echo 'basicConstraints=critical,CA:FALSE'
 echo 'keyUsage=critical,digitalSignature,keyEncipherment'
 echo "subjectAltName=$SAN"
} > "$BASE/csr/$NAME.ext"

if [ "$TYPE" = "ipsec" ]; then
 echo 'extendedKeyUsage=serverAuth,clientAuth' >> "$BASE/csr/$NAME.ext"
else
 echo 'extendedKeyUsage=serverAuth' >> "$BASE/csr/$NAME.ext"
fi

openssl x509 -req -sha256 -days 1825 \
 -in "$BASE/csr/$NAME.csr" \
 -CA "$BASE/cacert.pem" -CAkey "$BASE/private/cakey.pem" -CAcreateserial \
 -out "$BASE/certs/$NAME.crt" -extfile "$BASE/csr/$NAME.ext"

N=$(printf '%02d' $(( $(find "$BASE/newcerts" -maxdepth 1 -type f | wc -l) )))
cp "$BASE/certs/$NAME.crt" "$BASE/newcerts/$N-$NAME.pem"
```

```vim
chmod +x /usr/local/sbin/issue-cert

issue-cert fw-ipsec 200.100.10.2 IP:200.100.10.2 ipsec
issue-cert r2-ipsec 200.100.20.2 IP:200.100.20.2 ipsec
issue-cert www-worldskills www.worldskills.org DNS:www.worldskills.org tls
issue-cert rtmp-worldskills rtmp.worldskills.org DNS:rtmp.worldskills.org tls
issue-cert registry registry.itnsa.com DNS:registry.itnsa.com tls
issue-cert monitor monitor.itnsa.com DNS:monitor.itnsa.com tls
```

검증:

```vim
openssl x509 -in /etc/ssl/RootCA/cacert.pem -noout -text | egrep 'Subject:|CA:TRUE'
for cert in /etc/ssl/RootCA/newcerts/*; do openssl x509 -in "$cert" -noout -subject; done
for cert in /etc/ssl/RootCA/newcerts/*; do openssl verify -CAfile /etc/ssl/RootCA/cacert.pem "$cert"; done
```

```vim
#!/bin/bash
set -euo pipefail
TMP=$(mktemp)
trap 'rm -f "$TMP"' EXIT

printf '%s\n' \
 'dn: dc=itnsa,dc=com' \
 'objectClass: top' \
 'objectClass: dcObject' \
 'objectClass: organization' \
 'o: itnsa' \
 'dc: itnsa' \
 '' \
 'dn: ou=Employees,dc=itnsa,dc=com' \
 'objectClass: top' \
 'objectClass: organizationalUnit' \
 'ou: Employees' > "$TMP"

while IFS=$'\t' read -r group gid; do
 {
  echo
  echo "dn: cn=$group,ou=Employees,dc=itnsa,dc=com"
  echo "objectClass: top"
  echo "objectClass: posixGroup"
  echo "cn: $group"
  echo "gidNumber: $gid"
  if [ "$group" = "manager" ]; then
   echo "memberUid: manager"
  else
   echo "memberUid: manager"
   while read -r member; do
    [ -n "$member" ] && echo "memberUid: $member"
   done < <(/usr/bin/mariadb -N -B -u root -pSkill39** ldapdb -e     "SELECT username FROM USERTABLE WHERE \`group\`='$group' ORDER BY uid_number")
  fi
 } >> "$TMP"
done < <(/usr/bin/mariadb -N -B -u root -pSkill39** ldapdb -e 'SELECT groupname,gid_number FROM GROUPTABLE ORDER BY groupname')

while IFS=$'\t' read -r user pass grp ou uid gid home shell locked; do
 HASH=$(slappasswd -s "$pass")
 if [ "$locked" = 1 ]; then HASH="{CRYPT}!"; fi
 {
  echo
  echo "dn: uid=$user,ou=Employees,dc=itnsa,dc=com"
  echo 'objectClass: top'
  echo 'objectClass: inetOrgPerson'
  echo 'objectClass: posixAccount'
  echo 'objectClass: shadowAccount'
  echo "cn: $user"
  echo "sn: $user"
  echo "uid: $user"
  echo "ou: $ou"
  echo "uidNumber: $uid"
  echo "gidNumber: $gid"
  echo "homeDirectory: $home"
  echo "loginShell: $shell"
  echo "userPassword: $HASH"
 } >> "$TMP"
done < <(/usr/bin/mariadb -N -B -u root -pSkill39** ldapdb -e \
 'SELECT u.username,u.password,u.`group`,u.ou,u.uid_number,u.gid_number,u.home_directory,u.login_shell,COALESCE(l.locked,0) FROM USERTABLE u LEFT JOIN LOCKTABLE l ON u.username=l.username ORDER BY u.uid_number')

systemctl stop slapd
rm -f /var/lib/ldap/data.mdb /var/lib/ldap/lock.mdb
slapadd -n 1 -l "$TMP"
chown -R openldap:openldap /var/lib/ldap
systemctl start slapd
```

```vim
#!/bin/bash
set -u
DN=""
PW=""
ARGS=("$@")
for ((i=0;i<$#;i++)); do
 case "${ARGS[$i]}" in
  -D) DN="${ARGS[$((i+1))]}" ;;
  -w) PW="${ARGS[$((i+1))]}" ;;
 esac
done
USER=$(echo "$DN" | sed -n 's/^uid=\([^,]*\).*/\1/p')
[ -n "$USER" ] || exec /usr/bin/ldapwhoami "$@"

ROW=$(/usr/bin/mariadb -N -B -u root -pSkill39** ldapdb -e \
 "SELECT u.password,COALESCE(l.fail_count,0),COALESCE(l.locked,0) FROM USERTABLE u LEFT JOIN LOCKTABLE l ON u.username=l.username WHERE u.username='$USER';")
[ -n "$ROW" ] || exec /usr/bin/ldapwhoami "$@"
IFS=$'\t' read -r REAL FAIL LOCKED <<< "$ROW"

if [ "$LOCKED" = 1 ]; then
 echo 'ldap_bind: Invalid credentials (49)' >&2
 exit 49
fi

if [ "$PW" != "$REAL" ]; then
 FAIL=$((FAIL+1))
 if [ "$FAIL" -ge 3 ]; then
  /usr/bin/mariadb -u root -pSkill39** ldapdb -e \
   "INSERT INTO LOCKTABLE(username,fail_count,locked) VALUES('$USER',3,1) ON DUPLICATE KEY UPDATE fail_count=3,locked=1;"
  /usr/local/sbin/sync-ldap-from-mysql
  echo "$USER account is locked!"
 else
  /usr/bin/mariadb -u root -pSkill39** ldapdb -e \
   "INSERT INTO LOCKTABLE(username,fail_count,locked) VALUES('$USER',$FAIL,0) ON DUPLICATE KEY UPDATE fail_count=$FAIL;"
  echo 'ldap_bind: Invalid credentials (49)' >&2
 fi
 exit 49
fi

/usr/bin/mariadb -u root -pSkill39** ldapdb -e \
 "UPDATE LOCKTABLE SET fail_count=0 WHERE username='$USER';"
exec /usr/bin/ldapwhoami "$@"
```

## 13.4 LDAP 사용자 수 기반 quota 자동 계산

100GB를 사용자 수로 나누고 MiB 단위 올림한다. 21명일 때 4877M, testuser 포함 22명일 때 4655M이 된다.

```vim

```



```vim
#!/bin/bash
set -e
sss_cache -E || true
mapfile -t USERS < <(ldapsearch -LLL -x -H ldap://172.16.20.10 \
 -D 'cn=admin,dc=itnsa,dc=com' -w Skill39** \
 -b 'ou=Employees,dc=itnsa,dc=com' '(objectClass=posixAccount)' uid uidNumber gidNumber | \
 awk '/^uid:/{u=$2}/^uidNumber:/{id=$2}/^gidNumber:/{g=$2; print u":"id":"g}')
COUNT=${#USERS[@]}
[ "$COUNT" -gt 0 ] || exit 1
MIB=$(( (102400 + COUNT - 1) / COUNT ))
BLOCKS=$(( MIB * 1024 ))
echo "$MIB" > /var/lib/itnsa-quota-mib

for row in "${USERS[@]}"; do
 IFS=: read -r user uid gid <<< "$row"
 mkdir -p "/nfs/home/$user" "/nfs/backup/$user"
 chown "$uid:$gid" "/nfs/home/$user" "/nfs/backup/$user"
 chmod 700 "/nfs/home/$user" "/nfs/backup/$user"
 if [ ! -e "/nfs/home/$user/.backup-key" ]; then
  openssl rand -base64 32 > "/nfs/home/$user/.backup-key"
  chown "$uid:$gid" "/nfs/home/$user/.backup-key"
  chmod 600 "/nfs/home/$user/.backup-key"
 fi
 setquota -u "$uid" "$BLOCKS" "$BLOCKS" 0 0 /nfs/home
done

# 삭제된 계정의 quota를 0으로 정리
repquota -p /nfs/home 2>/dev/null | awk '$1 ~ /^[A-Za-z]/{print $1}' | while read -r old; do
 getent passwd "$old" >/dev/null || setquota -u "$old" 0 0 0 0 /nfs/home || true
done
```

## 13.5 80% 초과 자동 GPG backup

```vim
#!/bin/bash
USER="$1"
HOME_DIR="/nfs/home/$USER"
[ -d "$HOME_DIR" ] || exit 0
MIB=$(cat /var/lib/itnsa-quota-mib)
LIMIT=$(( MIB * 1024 * 1024 * 80 / 100 ))
USED=$(du -sb --apparent-size "$HOME_DIR" | awk '{print $1}')
[ "$USED" -gt "$LIMIT" ] || exit 0

FILE=$(find "$HOME_DIR" -maxdepth 1 -type f ! -name '.backup-key' -printf '%T@ %p\n' | sort -n | head -1 | cut -d' ' -f2-)
[ -n "$FILE" ] || exit 0
mkdir -p "/nfs/backup/$USER"
OUT="/nfs/backup/$USER/$(basename "$FILE").gpg"
tar --sparse -C "$HOME_DIR" -cf - "$(basename "$FILE")" | \
 gpg --batch --yes --pinentry-mode loopback \
 --passphrase-file "$HOME_DIR/.backup-key" \
 --symmetric --cipher-algo AES256 --compress-algo zlib \
 --output "$OUT"
chown --reference="$HOME_DIR" "$OUT"
chmod 600 "$OUT"
rm -f "$FILE"
```

# 19. FW 최종 nftables 정책

이 단계는 모든 서비스가 구성된 뒤 마지막에 적용한다. DB와 FILE 제한 규칙을 VPN 전체 허용보다 먼저 배치해야 채점의 nmap 결과가 맞는다.

FW의 인터페이스 기준:

```vim

```



```vim
flush ruleset

table inet fwfilter {
 set ssh_allowed {
  type ipv4_addr
  flags timeout
  timeout 120s
 }

 chain input {
  type filter hook input priority filter; policy drop;
  iifname "lo" accept
  ct state established,related accept
  ip protocol icmp accept

  # IKEv2 / ESP
  udp dport {500,4500} accept
  ip protocol esp accept

  # OpenVPN
  udp dport 1194 accept

  # 관리용 SSH: 내부 MAIN만
  ip saddr 172.16.10.10 tcp dport 22 accept
 }

 chain forward {
  type filter hook forward priority filter; policy drop;
  ct state established,related accept

  # MONITOR의 Node Exporter 수집은 특정 source에서만 허용
  ip saddr 172.16.10.20 ip daddr 172.16.20.10 tcp dport 9100 accept
  ip saddr 172.16.10.20 ip daddr 172.16.20.20 tcp dport 9100 accept

  # DB 접근 제한: LDAP, knock용 closed ports, MAIN SSH, knock 성공 SSH만
  ip daddr 172.16.20.10 tcp dport 389 accept
  ip daddr 172.16.20.10 tcp dport {3000,5000,8000} accept
  ip saddr 172.16.10.10 ip daddr 172.16.20.10 tcp dport 22 accept
  ip saddr @ssh_allowed ip daddr 172.16.20.10 tcp dport 22 accept
  ip daddr 172.16.20.10 drop

  # FILE은 NFSv4 TCP/2049만
  ip daddr 172.16.20.20 tcp dport 2049 accept
  ip daddr 172.16.20.20 drop

  # Site-to-Site VPN 전체 트래픽
  ip saddr 172.16.0.0/16 ip daddr 192.168.10.0/24 accept
  ip saddr 192.168.10.0/24 ip daddr 172.16.0.0/16 accept

  # OpenVPN 전체 트래픽
  ip saddr 10.0.0.0/24 ip daddr {172.16.0.0/16,192.168.10.0/24} accept
  ip saddr {172.16.0.0/16,192.168.10.0/24} ip daddr 10.0.0.0/24 accept

  # 사설망 -> 공인망 허용
  ip saddr {172.16.10.0/24,172.16.20.0/24,10.0.0.0/24} oifname "ens33" accept
 }
}

table ip nat {
 chain postrouting {
  type nat hook postrouting priority srcnat; policy accept;
  # S2S는 NAT 제외
  ip saddr {172.16.10.0/24,172.16.20.0/24,10.0.0.0/24} ip daddr 192.168.10.0/24 return
  # 공인망으로 나갈 때 masquerade
  ip saddr {172.16.10.0/24,172.16.20.0/24,10.0.0.0/24} oifname "ens33" masquerade
 }
}
```

```yaml
---
- name: Prepare and join target worker
  hosts: "{{ target }}"
  gather_facts: false
  become: true
  tasks:
    - name: Verify target parameter
      ansible.builtin.assert:
        that:
          - target is defined
          - target in ['worker1', 'worker2']

    - name: Clean stale state
      ansible.builtin.command:
        cmd: kubeadm reset -f --cri-socket unix:///run/containerd/containerd.sock
      failed_when: false

    - name: Remove stale CNI directories
      ansible.builtin.file:
        path: "{{ item }}"
        state: absent
      loop:
        - /etc/cni/net.d
        - /var/lib/cni
        - /etc/kubernetes

    - name: Restart containerd
      ansible.builtin.systemd:
        name: containerd
        state: restarted
        enabled: true

    - name: Create a fresh join command on MAIN
      ansible.builtin.command:
        cmd: kubeadm token create --print-join-command
      delegate_to: localhost
      register: join_command
      run_once: true
      environment:
        KUBECONFIG: /etc/kubernetes/admin.conf

    - name: Join Kubernetes cluster
      ansible.builtin.command:
        cmd: "{{ join_command.stdout }} --cri-socket unix:///run/containerd/containerd.sock"

    - name: Enable and restart kubelet
      ansible.builtin.systemd:
        name: kubelet
        state: restarted
        enabled: true

- name: Label and wait for target worker
  hosts: localhost
  connection: local
  gather_facts: false
  environment:
    KUBECONFIG: /etc/kubernetes/admin.conf
  tasks:
    - name: Wait for node object
      ansible.builtin.command:
        cmd: kubectl get node {{ target }}
      register: node_seen
      retries: 40
      delay: 3
      until: node_seen.rc == 0

    - name: Add worker label
      ansible.builtin.command:
        cmd: kubectl label node {{ target }} node-role.kubernetes.io/worker=worker --overwrite

    - name: Wait until Ready
      ansible.builtin.command:
        cmd: kubectl wait --for=condition=Ready node/{{ target }} --timeout=300s
```

# 23. 중요 포인트

1. `www.itnsa.com`을 zone 파일에 수동으로만 적으면 journal 채점에서 실패한다. 반드시 nsupdate로 DDNS journal을 만든다.
2. CoreDNS를 ClusterIP로만 두면 Worker IP:53 채점에서 실패한다. `hostNetwork: true`가 필요하다.
3. CoreDNS와 WebApp anti-affinity는 `requiredDuringSchedulingIgnoredDuringExecution`이어야 두 worker에 강제 분산된다.
4. Calico/MetalLB manifest의 image 경로가 공식 Registry로 남으면 Registry 채점에서 실패한다.
5. FILE이 NFSv3/RPC 포트를 열면 firewall 채점에서 실패할 수 있다. NFSv4 TCP/2049만 쓴다.
6. DB의 3000/5000/8000은 FW에서 accept하고 DB에는 listener가 없어야 nmap에서 closed로 보인다.
7. DB:22는 기본 filtered이고 knock 후에만 해당 Client IP를 nftables set에 넣는다.
8. DB와 FILE 제한 규칙을 VPN 전체 허용보다 먼저 배치한다.
9. APT Mirror는 DLBD 1의 공식 `Release`/`Packages.gz`를 그대로 복제한다. Version은 `13.2`, Codename은 `trixie`, Components는 `main contrib`, main 패키지 수는 `24847`이어야 한다.
10. Ansible remove는 노드 삭제만 해서는 안 된다. Worker에서 kubeadm reset과 CNI 정리를 해야 add가 다시 성공한다.
