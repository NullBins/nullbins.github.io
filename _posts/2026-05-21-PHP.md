## PHP(PHP: Hypertext Preprocessor) Language

<span class="text-red">※ 본 문서는 PHP 8.4.21를 기준으로 한다.</span>

### PHP 란?
- Client가 아닌 Web Server에서 실행되어 완성된 HTML 코드를 사용자 Browser에 전달하는 역할하는 프로그래밍 언어이다.

---

### *1. PHP Code Syntax*

#### APM (Web Server)

```vim
apt install -y apache2 php mariadb-server
```
>```php
>include 'login.php';
>include('login.php');
>```
- ```PHP``` or ```HTML``` 코드를 불러와 현재 실행중인 PHP 파일에 삽입

>```php
>isset() # PHP 변수가 선언 됐는지, 그 값이 null 아닌지 확인하는 함수
>!isset() # 변수가 없거나 null값이면 True
>```
- ```True(1)```: 변수가 존재하고 null값이 아닐 때
- ```False(0)```: 변수가 존재하지 않았거나 null값일 때

>```php
>$_GET['URL Parameter Value'] # ?param=value
>$_POST['HTTP Request Body Param Value'] # param=value
>$_GET['logout'] # ?page=logout
>```
- Client가 Server로 데이터를 전송할때 사용하는 ```GET```, ```POST``` 메서드(Method)

>```php
>session_start(); # 새로운 세션 생성 및 기존 저장된 세션 불러오기
>session_destroy(); # 현재 사용자의 세션에 연결된 모든 데이터를 삭제
>header('Location: index.php'); # index.php로 리다이렉트
>header('Content-Type: application/octet-stream');
>header('Content-Disposition: attachment; filename=\"image.jpg\"');
># 파일 다운로드 하도록 창을 띄움
>exit; # header('Location: index.php'); 처럼 리다이렉트 한 후에는 밑의 코드를 읽지 않도록 꼭 exit 해줘야 함.
>```
- ```header()```: HTTP 헤더 정보를 직접 전송할 때 사용하는 함수

>```php
>$arr = []; # 배열
>trim(); # 앞뒤 공백제거
>password_hash("password", PASSWORD_DEFAULT);
>password_verify("password", "암호화 된 패스워드 해시");
>nl2br(); # next line('\n')을 <br>로 바꿔 줌.
>```

### *2. PHP Database Connection*

#### APM (Web Server)

```vim
apt install -y mysql-php
```
- PDO(PHP Data Objects), mysqli
>```php
><?php
>$host='192.168.10.10';
>$port='3306';
>$db='kknock_web';
>$user='kknock_user';
>$pass='password';
>
>try {
>   $db_connect = new PDO("mysql:host={$host};port={$port};dbname={$db}", $user, $password);
>   $db_connect->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
>} catch (PDOException $e) {
>   echo "<h2>DB Status: Stopped</h2>";
>   echo "<hr><p>" . htmlspecialchars($e->getMessage) . "</p>";
>   exit;
>}
>
>session_start();
>?>
>```
- ```ATTR_ERRMODE```: 에러 모드 사용
- ```ERRMODE_EXCEPTION```: PHP 경고 대신 예외(Exception) 발생. try-catch로 에러 관리

>```php
>$db = new PDO(); # PDO 객체 생성
>$state = $db->prepare("SELECT * FROM users ORDER BY userid ASC"); # SQL문을 Template 형태로 미리 준비함. (나중에 실제 데이터를 바인딩, SQL Injection 방지)
>$state->execute();
>$result = $state->fetchAll(PDO::FETCH_ASSOC); # 연관(ASSOCIATIVE) 배열 구조로 변수에 담김
>$db->lastInsertId(); # 방금 INSERT로 추가된 AUTO_INCREMENT의 값을 가져오는 함수
>```
- ```FETCH_ASSOC```: Associative Array 구조의 2차원 배열

> [ $result 구조 ]
>```text
>[
>   0 => [
>           "id" => "1",
>           "username" => "choi"
>   ],
>   1 => [
>           "id" => "2",
>           "username" => "kim"
>   ]
>]
>```
